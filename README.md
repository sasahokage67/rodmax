# RODMAX ⚓ // Глубоководный Аркадный Симулятор Рыбалки

> **Реальное управление жестами рук через веб-камеру прямо в браузере (60 FPS), прозрачная система вероятностей вылова, 1080p кинематографичные катсцены и личный кабинет рыболова.**

---

## 🎮 Ключевые особенности

- 🎥 **Webcam Optical Motion Tracking:** Распознавание физических движений рук в реальном времени через веб-камеру (`navigator.mediaDevices` + HTML5 Canvas diffing). Взмах рукой для заброса, резкий рывок для подсечки и контроль высоты ладони при вываживании.
- ⌨️ **Гибридный резерв:** Мгновенное переключение на классическое управление мышью (`ЛКМ`) и клавиатурой (`ПРОБЕЛ` / `W / S`).
- ⚖️ **Честная система процентов (100% Drop Rates):**
  - `COMMON` — Старый Сапог: **40.0%**
  - `UNCOMMON` — Серебристый Лосось: **28.0%**
  - `RARE` — Пузатый Золотой Карась: **16.0%**
  - `EPIC` — Глубинный Удильщик: **8.5%**
  - `EPIC` — Доисторический Мегалодон: **4.5%**
  - `SECRET` — Левиафан Бездны: **2.0%**
  - `GODLY` — Солнечный Небесный Кит: **0.8%**
  - `ARCANE` — Арканная Неоновая Медуза: **0.2%** (1 к 500)
- 🗃️ **Личный кабинет рыболова & Садок:**
  - Bento-сводка карьеры (баланс монет, общий улов, вес и ценность садка).
  - Пожизненный реестр поимок (`ПОЙМАНО: xN`) и рекордных весов трофеев.
  - Продажа рыбы из садка (оптом или по отдельным видам).
  - 16-битная шкала опыта (EXP) и ранги мастерства.
  - Кастомизация аватарки (10 уникальных пиксельных артов).
- 🎬 **1080p видеоряд и бестиарий:** Полноценные видео-поимки для каждого вида, включая старый сапог.

## 🕹️ Управление

| Действие | Жест на веб-камеру | Клавиатура / Мышь |
| :--- | :--- | :--- |
| **Заброс лески** | Взмах ладонью вверх | `ПРОБЕЛ` или Клик |
| **Подсечка (! КЛЮЕТ !)** | Резкий рывок рукой вверх | `ПРОБЕЛ` или Клик |
| **Подъем планки натяжения** | Поднять ладонь выше в кадре | Зажатие `ЛКМ` / `W` / `[▲]` |
| **Спуск планки натяжения** | Опустить ладонь ниже | Отпустить `ЛКМ` / `W` |

## 🛠️ Стек технологий

- **Фреймворк:** React 18, TypeScript, Vite 5
- **Стилизация:** Tailwind CSS, PostCSS, Lucide Icons
- **Аудио:** Синтезированный Web Audio API (чиптюн 8-bit эффекты)
- **Компьютерное зрение:** Оптический трекинг движения на HTML5 Canvas (без сторонних тяжелых библиотек, zero-lag)
- **Эффекты:** Canvas Confetti, CSS CRT Scanlines

## 🚀 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/sasahokage67/rodmax.git
cd rodmax

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production-билда
npm run build
```
