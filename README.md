# RODMAX ⚓ // Глубоководный Аркадный Симулятор Рыбалки

> **Реальное управление жестами рук через веб-камеру прямо в браузере (60 FPS), прозрачная система вероятностей вылова, 1080p кинематографичные катсцены и личный кабинет рыболова.**

---

## 🎮 Ключевые особенности

- 🎥 **100% Webcam Optical Motion Tracking:** Физическое управление жестами рук через веб-камеру прямо в браузере (60 FPS) без задержек. Взмах ладонью вверх для заброса, резкий рывок для подсечки и оптическое удержание руки на рыбе при вываживании.
- 🎯 **Механика «Рука на рыбе»:** Ладонь игрока проецируется в кадр арены — удерживайте руку точно на рыбе, чтобы заполнить шкалу вываживания до 100%.
- ✨ **Система мутаций Shiny (шанс 10%):** Редчайшие переливающиеся золотым свечением особи с удвоенной рыночной стоимостью (`2x Coins`) и бонусом к опыту.
- ⚡ **Хардкорная физика вываживания:** Увороты рыбы, узкая зона захвата и возрастающая сложность в зависимости от редкости добычи.
- ❓ **Интрига улова:** Вид, вес и редкость рыбы остаются засекреченными до момента победного вылова.
- ⚖️ **Честная система процентов (100% Drop Rates):**
  - `COMMON` — Старый Сапог: **40.0%**
  - `UNCOMMON` — Серебристый Лосось: **28.0%**
  - `RARE` — Пузатый Золотой Карась: **16.0%**
  - `EPIC` — Глубинный Удильщик: **8.5%**
  - `EPIC` — Доисторический Мегалодон: **4.5%**
  - `SECRET` — Левиафан Бездны: **2.0%**
  - `GODLY` — Солнечный Небесный Кит: **0.8%**
  - `ARCANE` — Арканная Неоновая Медуза: **0.2%** (1 к 500)
- 🗃️ **Личный кабинет рыболова & Садок:**
  - Bento-сводка карьеры (баланс монет, общий улов, вес и ценность садка).
  - Пожизненный реестр поимок (`ПОЙМАНО: xN`) и рекордных весов трофеев.
  - Мгновенная продажа рыбы из садка (без зависания пустых карточек).
  - 16-битная шкала опыта (EXP) и ранги мастерства.
  - Кастомизация аватарки (10 уникальных deep-sea артов).
- 🎬 **1080p видеоряд и бестиарий:** Полноценные видео-поимки для каждого вида, включая старый сапог.

## 🕹️ Управление

| Действие | Оптический жест (Веб-камера) | Экранная кнопка |
| :--- | :--- | :--- |
| **Заброс снасти** | Взмах ладонью вверх перед камерой | Кнопка «Забросить удочку» |
| **Подсечка (! КЛЮЕТ !)** | Резкий взмах рукой вверх | Кнопка «Подсечь рыбу» |
| **Вываживание добычи** | **Наведение ладони на рыбу** в окне камеры | — |

> ⚠️ *Клавиатура, мышь и сенсорное перетаскивание намеренно заблокированы при вываживании: игра построена исключительно вокруг прямого оптического взаимодействия через веб-камеру.*

## 🛠️ Стек технологий

- **Фреймворк:** React 18, TypeScript, Vite 5
- **Стилизация:** Tailwind CSS, PostCSS, Lucide Icons
- **Аудио:** Синтезированный Web Audio API (чиптюн 8-bit эффекты)
- **Компьютерное зрение:** Оптический трекинг движения на HTML5 Canvas (без сторонних тяжелых библиотек, zero-lag)
- **Эффекты:** Canvas Confetti, CSS CRT Scanlines

## 🚀 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/sasahokage67/rodmax.git
cd rodmax

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production-билда
npm run build
```
